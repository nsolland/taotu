# This May Be Relevant

It did not begin with a book.

It began when something large received a description far too small for it.

That happens all the time in research. A result is promising but bounded. A mechanism appears to work, but only in a frozen synthetic world. An effect reproduces, but the sample is small. A new explanation survives the first attempt to kill it, but has yet to face the test that really matters.

In such circumstances, language should be cautious.

That is not a problem.

The problem begins when the language becomes so cautious that it starts to conceal what the result actually says.

We had a tendency to do exactly that.

An entire chain of findings might end with phrases such as:

> an interesting candidate structure

or:

> bounded synthetic mechanism-existence result

Both descriptions could be correct.

They could also be the linguistic equivalent of calling a landslide a minor geological adjustment.

This is not, therefore, a book about shouting louder.

It is a book about proportion.

Between evidence and claim.

Between claim and implication.

Between what we have actually shown and what we suspect it might mean.

Exaggeration collapses these distinctions. It turns a hypothesis into a fact, a pilot result into a universal law, and a good week in the repository into a new chapter in human history.

Understatement does the opposite. It can reduce a genuine result to a footnote because that feels safer.

Both are inaccurate.

The first conceals uncertainty.

The second conceals significance.

*The Art of the Underdrivelse* inhabits this slightly embarrassing space.

It takes limitations seriously. It refuses to fill gaps with enthusiasm. It does not write *consciousness* when the test demonstrates internal relevance. It does not write *intelligence* when all it has is a necessary mechanism. It does not write *universal* when the world consisted of a few states and a test that took less time than lunch.

But it also refuses to pretend that every result is small simply because it is new.

The first question was something like:

> Can intelligence be portable?

It was quickly refined to:

> Can a VIC-20 perhaps carry the seed?

A modest clarification.

It was also the moment we should have realized this was going to become a book.
