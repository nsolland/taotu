# Agent brief — Chapter 001: We Have to Move to Switzerland

[Read chapter and PDF](../../chapters/001/README.md) · [Publication manifest](../../releases/001/manifest.json) · [Global agent rules](../../AGENTS.md)

**Status:** English literary adaptation of a Norwegian reconstructed source; first-person memory and GitHub commit evidence are different classes of claim. The original Gemini conversation is unavailable.

## Tasks

1. Identify where the narrator's subjective certainty exceeds the documented evidence.
2. Separate remembered dialogue, later reconstruction, GitHub timestamps, and interpretations of code constants.
3. Test the argument that a working simulation does not establish a universal law or consciousness. What additional evidence would be required?
4. Evaluate whether the opening fairly describes the wife's role without pretending to verify her exact words.
5. Propose a precise correction or alternative reading, without inventing the missing transcript.
6. If translating, flag culturally specific humor and shifts in epistemic confidence.

**Do not:** Treat the alleged “God Code” as proven, invent private records, or confuse an author's recollection with independently witnessed history.
